# Security policy

## Reporting a vulnerability

If you find a security issue in this repository or in Brain Agents AI
more broadly, please do not open a public GitHub issue.

Instead, contact us privately at
[https://brainagents.ai/security](https://brainagents.ai/security).

We aim to acknowledge every report within one business day and to
provide a first substantive response within five business days.

## Scope

This repository only hosts an interactive Cloud Shell tutorial for
customer onboarding. The tutorial runs entirely in the customer's own
Cloud Shell with the customer's own credentials. Brain Agents AI never
executes the tutorial commands on its side.

For security disclosures related to the Brain Agents AI product itself
(the dashboard, the ingestion pipeline, the agents), use the same
contact URL above.

## Supported versions

This tutorial is maintained continuously. The version of the file on
the `main` branch is the only supported version.
